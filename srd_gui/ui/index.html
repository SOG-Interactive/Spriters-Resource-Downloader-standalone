A SOG Interactive (Stroke of Genius Interactive) tool

Download sprites from The Spriters Resource

Based on Spriters-Resource-Downloader by torresflo, who wrote the original command-line downloader this app grew from (GPL v3).

Paste the address of a game page, pick where the files should go, then either grab everything or inventory the page first and tick exactly what you want.

How the browser window works

The site protects itself with a "Verify you are human" check that only a real browser can pass. This app opens a real browser window next to it. If that window shows the check, click it yourself once; the app then reads pages and files through that same window. Your clearance is remembered between runs, so you will rarely see it again.
